## 📋 Ringkasan Misi & Pembahasan

1. **Misi 1: Pemetaan Konsep (Conceptual Mapping)**
   - Menghubungkan fase *Reconnaissance* dengan kerangka kerja **Cyber Kill Chain** dan **MITRE ATT&CK** sebelum menyentuh sistem target.

2. **Misi 2: Pelacakan Identitas (Domain & IP Footprinting)**
   - Melakukan investigasi pasif menggunakan **WHOIS** dan perintah `dig` di terminal Linux.
   - **Hasil Temuan:** Mendapatkan IP utama target (`50.116.1.184`) dan Nameserver Linode.

3. **Misi 3: Pencarian Kebocoran Data (Google Dorks / GHDB)**
   - Menggunakan teknik pencarian lanjutan terbatas pada domain terotorisasi untuk mendeteksi direktori terbuka (*directory listing*) seperti `Index of /images`.

4. **Misi 4: Intelijen Sumber Terbuka (OSINT)**
   - Mengumpulkan informasi publik mengenai teknologi server (Apache, Linux/Debian) serta daftar subdomain terkait secara etis tanpa melakukan serangan/eksploitasi.
